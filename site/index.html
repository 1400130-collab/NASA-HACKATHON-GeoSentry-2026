02The measurement측정

A slope creeps … cm. We can see that from orbit.

사면이 … cm 움직입니다. 궤도에서 그걸 봅니다.

NISAR bounces a radar wave off every slope each 12 days. Line up two echoes and the shift between them is how far the ground moved. It works through cloud, rain and darkness.

NISAR는 12일마다 모든 사면에 레이더파를 쏩니다. 두 번의 반사파를 겹쳐 보면, 어긋난 만큼이 지표가 움직인 거리입니다. 구름, 비, 밤에도 됩니다.

04The machine learning머신러닝

Three models, one job each. Spot the movement. Rank the slopes. Predict how far the debris runs.

모델 셋, 각자 할 일 하나. 움직임을 찾고, 사면 순위를 매기고, 토석류가 얼마나 멀리 가는지 예측합니다.

01Neural network신경망

The detector

탐지 모델

A GRU reads each slope's radar history on three orbits and decides: real movement, or noise? It learned by finding fake slips hidden in real noise.

GRU가 세 궤도의 사면별 레이더 이력을 읽고 판단합니다. 실제 이동인가, 잡음인가? 실제 잡음 속에 숨긴 가상의 이동을 찾으며 학습했습니다.

11How it keeps running계속 돌아가는 방식

Every 12 days, the list updates itself.

12일마다 목록이 스스로 갱신됩니다.

  1. 01NISAR passesNISAR 통과
    Every land area is imaged every 12 days, day or night, through cloud.모든 육지를 12일마다, 밤낮없이, 구름을 뚫고 촬영.
  2. 02Fetch the pairs영상쌍 받기
    Interferograms (GUNW) from NASA's ASF archive, read over HTTPS without downloading whole files.NASA ASF 보관소의 간섭도(GUNW)를 파일 전체를 받지 않고 HTTPS로 읽음.
  3. 03Rerun the pipeline파이프라인 재실행
    Movement, detector, ranking and rule. About 4 minutes for the regional build on a laptop.이동량, 탐지, 순위, 규칙. 노트북에서 지역 단위 실행에 약 4분.
  4. 04Update the map지도 갱신
    Map and sheets are static files. No server to run, any web host works.지도와 점검표는 정적 파일. 서버가 필요 없고 어느 웹 호스트든 가능.
  5. 05Print the sheet점검표 인쇄
    One page per county, in Korean, with the reasons for each slope.시·군별 한 장, 한국어, 사면마다 이유 표시.
